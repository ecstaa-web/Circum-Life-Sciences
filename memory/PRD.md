# Nereïs — plateforme de vente de yachts

Maison de yachts d’exception (Monaco · Saint-Tropez · Genève).

## Site

- Accueil cinématique, collection filtrable, fiches yacht, maison, expériences, concierge, audience privée (FR/EN).
- Stack : HTML/CSS/JS + Express (`frontend/`, port 3000) et API FastAPI optionnelle (`backend/`).

## Lancer

```bash
cd frontend && npm install && npm start
```

API locale : `GET /api/yachts`, `GET /api/yachts/:id`, `POST /api/inquiries`.
